# Python Application Energy Consumption

This repository accompanies the thesis *"Python Application Energy Consumption: Investigating Operating System, Python Version and Hardware Impact on the Energy Consumption of Application Benchmarks"*.

## Overview

This repository provides a comprehensive experimental framework for measuring and analyzing the energy consumption of Python applications across different system configurations. It includes all source code, experimental data, and results referenced in the associated thesis.

## Contents

- **Experimental Framework**: Complete codebase for running energy consumption benchmarks
- **Application Benchmarks**: Suite of test applications used in the energy analysis
- **Results Dataset**: All experimental results and measurements reported in the thesis
- **Analysis Tools**: Scripts for processing and visualizing energy consumption data

## Research Focus

This project investigates how the following factors impact Python application energy consumption:

- **Operating Systems**: Cross-platform energy efficiency analysis
- **Python Versions**: Performance and energy trade-offs across Python releases  
- **Hardware Configurations**: Impact of different system architectures
